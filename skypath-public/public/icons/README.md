# Icon Requirements

Place application icons here for PWA manifest and home screen installation.

Required icons:
- `icon-192.png` — 192x192 PNG
- `icon-512.png` — 512x512 PNG

Optional icons for Android/iOS compatibility:
- `maskable-icon-512.png` — 512x512 maskable PNG
- `icon-256.png` — 256x256 PNG
